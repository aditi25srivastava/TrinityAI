# Trinity AI - Multimodal Digital Twin

Trinity AI is a state-of-the-art, fully autonomous 3D Digital Twin powered by a multimodal architecture. It seamlessly bridges a Unity 3D frontend with a Python FastAPI and LangGraph backend, providing real-time voice, vision, and agentic capabilities.

## 🚀 10 Core Features

1. **Persistent Memory System**
   - **How it works**: Uses a local Vector Database (ChromaDB) and `SentenceTransformerEmbeddings` to store and retrieve long-term conversational memory.
   - **Impact**: Maintains deep context across sessions, learning user preferences and seamlessly recalling past interactions.

2. **Emotion Detection (Affective Computing)**
   - **How it works**: The AI natively analyzes voice sentiment and webcam facial expressions.
   - **Impact**: The LLM dynamically outputs a corresponding emotional state (happy, sad, frustrated), which drives the Unity avatar's facial blendshapes in real-time.

3. **Vision + Voice Agent**
   - **How it works**: A fully multimodal pipeline transmitting base64 audio, webcam feeds, and screen-share contexts directly to Gemini 2.5 Vision.
   - **Impact**: You can ask the AI to "Explain this LeetCode problem" while sharing your screen, and it will instantly see and solve it verbally.

4. **Real-Time Avatar Lip Sync**
   - **How it works**: Audio payloads generated by the backend TTS are analyzed in real-time by Unity to generate dynamic visemes.
   - **Impact**: Creates a highly immersive, human-like interaction with accurate jaw and mouth movements tied directly to speech amplitude.

5. **Offline Fallback AI (Edge AI)**
   - **How it works**: If cloud APIs fail or internet connectivity drops, the system gracefully falls back to local edge processing.
   - **Impact**: Uses local Whisper STT, Edge-TTS, and quantized local LLMs to ensure the AI remains fully functional even while completely offline.

6. **Agentic Actions**
   - **How it works**: Equipped with system-level tools rather than just conversational capabilities.
   - **Impact**: The AI can actively open applications (e.g., Safari, Calculator), search files, and perform tasks on the host machine.

7. **RAG Knowledge Engine**
   - **How it works**: Integrates a Retrieval-Augmented Generation (RAG) pipeline capable of digesting PDFs, research papers, and text notes.
   - **Impact**: Users can upload complex domain knowledge (e.g., DSA notes) and the AI will reliably extract and synthesize answers from those private documents.

8. **Multi-Agent Collaboration**
   - **How it works**: Powered by LangGraph, a Master Supervisor node orchestrates requests across 4 specialized sub-agents.
   - **Impact**: Intelligently delegates tasks to a Coding Agent, Research Agent, Career Agent, or Interview Agent to ensure optimal expert-level responses.

9. **Digital Twin Personality**
   - **How it works**: A dynamic parameter injected into the LLM system prompt directly from the Unity client via keyboard shortcuts.
   - **Impact**: Users can instantly toggle the AI's persona between Professional, Teacher, Interviewer, and Mentor modes, completely altering its behavioral style.

10. **Analytics Dashboard**
    - **How it works**: A real-time telemetry system tracking latency, TTS generation times, and AI self-assessed satisfaction/success rates.
    - **Impact**: Provides a beautiful FastAPI HTML/Chart.js dashboard to monitor system health and validate engineering maturity.

## 🛠️ Tech Stack
- **Frontend**: Unity 3D (C#), WebSockets, Blendshape Animation
- **Backend**: Python 3, FastAPI, LangChain, LangGraph, Uvicorn
- **AI Models**: Google Gemini 2.5 Pro/Flash, OpenAI Whisper (Offline), HuggingFace Transformers
- **Databases**: ChromaDB (Vector Search), SQLite (Analytics)

##  Getting Started

### 1. Start the Backend
```bash
# Navigate to the backend directory
cd trinity_ai

# Create a virtual environment and install dependencies
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Start the server
uvicorn app.main:app --host 0.0.0.0 --port 8001
```

### 2. View Analytics
Navigate to `http://localhost:8001/dashboard` in your browser.

### 3. Start the Frontend
Open the `trinity` Unity project, hit **Play**, and hold the **Spacebar** to speak! Use keys `1-4` to switch personalities, and `S` to share your screen!
